# Manual Testing Project – E-commerce Website

## Application Tested
OpenCart Demo Website

https://demo.opencart.com

## Objective
The objective of this project is to perform manual testing on an e-commerce web application and document the testing process including test scenarios, test cases, bug reports, and exploratory testing notes.

## Testing Scope
- User login
- Product search
- Product page
- Add to cart
- Cart management
- Checkout flow

## Testing Type
Manual Functional Testing and Exploratory Testing

## Tools Used
- Browser: Google Chrome
- Documentation: Markdown
