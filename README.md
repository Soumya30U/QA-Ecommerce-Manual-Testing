# Manual Testing Project – E-commerce Web Application

## Project Overview

This project demonstrates manual testing of an e-commerce web application. The testing effort focuses on validating key user flows such as authentication, product browsing, search functionality, cart operations, and checkout behavior. The goal is to evaluate the application's functional behavior and identify potential usability or system defects.

The testing activities include the creation of structured test documentation, execution of manual test cases, and defect reporting based on observed system behavior.

---

## Application Under Test

OpenCart Demo E-commerce Website
https://demo.opencart.com

OpenCart is an open-source e-commerce platform that allows users to browse products, manage shopping carts, and complete online purchases.

---

## Testing Objectives

The primary objectives of this testing activity are:

* Validate core functionalities of the e-commerce application
* Ensure major user flows operate as expected
* Identify functional defects and usability issues
* Document test scenarios, test cases, and bug reports

---

## Testing Scope

The following functional modules were included in the testing scope:

### User Authentication

* Login page accessibility
* Login validation with valid and invalid credentials
* Error message verification

### Product Search

* Searching for products using keywords
* Partial keyword search
* Handling of non-existing search queries

### Product Details

* Accessing product pages
* Verification of product information display
* Product image loading

### Cart Functionality

* Adding products to cart
* Updating product quantity
* Removing items from cart
* Cart information accuracy

### Checkout Process

* Navigation to checkout
* Validation of checkout flow
* Order summary verification

---

## Testing Approach

The testing was performed using the following methods:

**Manual Functional Testing**

* Executing predefined test cases to validate expected system behavior.

**Exploratory Testing**

* Performing unscripted testing to explore application functionality and identify potential issues.

## Key Observations

During testing, the following observations were noted:

* Core navigation and product browsing work as expected.
* Search functionality occasionally returns broad results.
* Some UI and usability improvements could enhance user experience.

The testing process successfully evaluated several core functionalities of the OpenCart demo e-commerce application. The documented artifacts provide an overview of the testing approach, executed test cases, and identified issues.
