# Test Scenarios

## Login Module

1. Verify login page loads successfully
2. Verify login with valid email and password
3. Verify login fails with incorrect password
4. Verify login fails with unregistered email
5. Verify validation messages appear when fields are empty

## Product Search

6. Verify user can search for products using the search bar
7. Verify relevant products appear in search results
8. Verify search works with partial product names
9. Verify message appears when no results are found

## Product Page

10. Verify user can open product details page
11. Verify product information is displayed correctly
12. Verify product images load correctly

## Cart

13. Verify user can add product to cart
14. Verify cart icon updates when product is added
15. Verify user can remove product from cart

## Checkout

16. Verify checkout button works from cart page
17. Verify checkout page loads successfully
18. Verify user can proceed through checkout steps
