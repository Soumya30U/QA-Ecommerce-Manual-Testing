# Exploratory Testing Notes

Application:
OpenCart Demo Website

Testing Focus:
Product browsing and cart functionality.

Testing Method:
Unscripted exploratory testing while navigating through product pages.

---

## Observations

1. Navigation menu loads categories correctly.
2. Product listings display image, price, and rating.
3. Add to Cart functionality works correctly for most products.
4. Search functionality returns broad results.

---

## Usability Observations

- Website layout is intuitive.
- Categories are clearly visible in the navigation menu.
- Product pages contain sufficient product information.

---

## Potential Issues

- Product images occasionally load slowly.
- Search results sometimes include unrelated items.

---

## Suggestions

1. Improve search filtering for more accurate results.
2. Optimize image loading performance.
3. Add advanced filtering options for products.
